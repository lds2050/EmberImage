# EmberImage v0.4.0 需求文档

> 版本主题：样例库与参数复用
> 文档状态：开发中
> 基线版本：v0.3.2
> 更新时间：2026-08-28

## 1. 版本概述

v0.4.0 新增独立的“样例”菜单，把优质成图、完整提示词和生成配置组织成可浏览、可搜索、可复用的灵感库。用户不必从空白提示词开始，可以先查看效果，再把对应提示词与参数一键带回“开始”页继续修改或直接生成。

本版不新增模型接口，也不改变现有文字生图请求。原计划中的图生图、整图编辑和 Mask 局部编辑整体顺延至 v0.5.0。

## 2. 产品目标

1. 降低长提示词的使用门槛，让新用户快速理解“什么样的提示词会得到什么效果”。
2. 将图片、提示词和参数作为一个完整预设复用，避免只复制提示词后遗漏尺寸或质量设置。
3. 提供清晰的分类、搜索和详情查看能力，样例数量增加后仍易于查找。
4. 使用现有生成图片作为首批内容，不发送额外请求、不产生额外费用。
5. 严格控制内置图片体积，避免显著增加安装包大小。

## 3. 非目标

- 用户自行创建、编辑或删除内置样例；
- 从网络动态下载样例；
- 云端样例后台或内容运营系统；
- 图生图、参考图生成、整图编辑或 Mask 局部编辑；
- 把样例图片本身作为模型输入；
- 一键生成时跳过用户确认并立即产生费用。

## 4. 信息架构

左侧菜单调整为：

1. 开始
2. 样例
3. 画廊
4. 设置

“样例”位于“开始”和“画廊”之间，并显示当前内置样例数量。

## 5. 首批样例

v0.4.0 内置 6 个由用户现有生成记录整理出的样例：

| 分类 | 样例 | 原始配置 |
| --- | --- | --- |
| 春日 | 春日递缰 | 2160×3840、高质量、PNG、1 张 |
| 春日 | 桃林递花 | 2160×3840、高质量、PNG、1 张 |
| 雨夜 | 雨夜共伞 | 2160×3840、高质量、PNG、1 张 |
| 雨夜 | 窗下奉茶 | 2160×3840、高质量、PNG、1 张 |
| 水乡 | 晨雾采莲 | 1024×1536、高质量、PNG、1 张 |
| 冬日 | 雪夜围炉 | 2160×3840、高质量、PNG、1 张 |

分类固定为“全部、春日、雨夜、水乡、冬日”。后续新增样例时允许增加分类，但“全部”始终位于第一项。

## 6. 页面交互

### 6.1 分类与搜索

- 页面顶部左侧显示分类按钮及每类数量；
- 默认选中“全部”；
- 切换分类后立即过滤，不重新加载页面；
- 右侧提供搜索框，可搜索标题、简介、标签和完整提示词；
- 分类和搜索条件同时生效；
- 无匹配结果时显示空状态和调整筛选提示。

### 6.2 样例卡片

每张卡片显示：

- 压缩预览图；
- 分类；
- 样例标题；
- 一句话场景说明；
- 3 个内容标签；
- 最多两行提示词预览；
- 尺寸、质量和背景等主要参数；
- “使用”按钮和“查看详情”入口。

点击图片区域打开详情；点击“使用”直接复用提示词和全部可恢复参数。

### 6.3 样例详情

详情弹窗采用左右布局：

- 左侧完整展示样例图；
- 右侧显示分类、标题、说明、全部参数和完整提示词；
- 提示词区域可独立滚动；
- 提供“复制提示词”；
- 提供“使用此样例”；
- 支持关闭按钮、点击遮罩关闭和 `Esc` 关闭。

### 6.4 一键复用

点击“使用”或“使用此样例”后：

1. 关闭样例详情；
2. 切换到“开始”页；
3. 恢复完整提示词；
4. 恢复尺寸、质量、数量、背景、格式、压缩率和内容过滤；
5. 不修改当前连接、模型、API Key、请求超时或流式开关；
6. 不自动提交生成请求；
7. 聚焦提示词输入框，并提示“已套用某某样例的提示词和参数”。

如果当前连接未配置或未加载密钥，仍允许复用，用户只在点击“开始生成”时被引导到设置。

## 7. 数据结构

每个静态样例包含：

```json
{
  "id": "spring-riding",
  "title": "春日递缰",
  "category": "spring",
  "summary": "春日古道上策马同行，把缰绳递向镜头。",
  "imagePath": "../assets/presets/spring-riding.webp",
  "tags": ["古风", "POV", "骑马"],
  "prompt": "完整提示词",
  "parameters": {
    "size": "2160x3840",
    "quality": "high",
    "n": 1,
    "background": "auto",
    "outputFormat": "png",
    "outputCompression": null,
    "moderation": "auto",
    "stream": false
  }
}
```

样例数据只包含公开展示所需内容，不包含：

- API Key 或加密数据；
- API Base URL；
- 连接名称或账户信息；
- Request ID、日志和 usage；
- 原图本地绝对路径；
- 生成历史 ID。

## 8. 图片资源策略

- 使用现有成图生成 900 px 宽的 WebP 预览；
- 预览压缩不改变样例中保存的生成参数；
- 不将 2K/4K 原图打入安装包；
- 6 张预览图总体积控制在 1 MB 内；
- 图片仅用于视觉示例，不可从客户端导出为原始生成文件；
- 详情图使用 `object-fit: contain`，卡片图允许适度裁切。

## 9. 安全与隐私

- 样例库完全离线，不触发网络请求；
- 浏览、搜索和查看详情不产生请求日志；
- 只有用户回到“开始”页并主动点击“开始生成”时才发送 API 请求；
- “复制提示词”通过主进程剪贴板能力完成；
- 预设数据经过静态转义，渲染时不得直接插入未转义 HTML。

## 10. 兼容与迁移

- 不修改 `config.json`、`history.json` 或 `request-logs.json` 的结构；
- v0.3.x 连接配置、密钥、历史和图片保持原位；
- 没有历史记录的新安装仍能看到全部内置样例；
- 样例复用使用现有参数校验；如果未来模型或兼容服务不支持某个尺寸，应在“开始”页正常显示校验或 API 错误，不静默改写。

## 11. 验收标准

- [ ] 左侧菜单显示“开始、样例、画廊、设置”，版本显示 v0.4.0。
- [ ] 样例页展示 6 张现有成图的压缩预览。
- [ ] “全部、春日、雨夜、水乡、冬日”的数量正确。
- [ ] 分类筛选和搜索可组合使用。
- [ ] 每张卡片可查看完整提示词和参数。
- [ ] “复制提示词”能够写入系统剪贴板并给出成功提示。
- [ ] 从卡片或详情点击“使用”后，提示词和全部生成参数正确恢复。
- [ ] 复用不会自动生成、不会切换连接，也不会修改 API Key。
- [ ] 详情弹窗支持按钮、遮罩和 `Esc` 三种关闭方式。
- [ ] 样例浏览过程不产生 API 请求或请求日志。
- [ ] 内置预览资源总大小不超过 1 MB。
- [ ] `npm test` 与 `npm run check` 通过。
- [ ] Windows x64、macOS arm64、macOS x64 可正常显示 WebP 预览。

页面采用“可筛选的示例卡片 + 详情 + 复用”的组织方式，参考 OpenAI Developers 的 [Showcase 分类浏览结构](https://developers.openai.com/showcase)，但内容和交互针对 EmberImage 本地桌面工作流重新设计。
