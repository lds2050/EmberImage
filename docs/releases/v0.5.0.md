## 本次更新

- 新增图片编辑：导入 1–16 张本地图片（选择器、拖拽或粘贴），用自然语言完成整体重绘、风格转换、元素增删与多参考图合成。
- 新增 Mask 局部编辑：全屏画布涂抹希望修改的区域，支持画笔/橡皮、撤销/重做、缩放与拖动查看。
- 画廊区分文字生图、整体编辑与局部编辑记录，支持继续编辑、按原参数再次编辑和原图/结果对比。
- 编辑历史保存输入图与 Mask 的独立副本，原文件被移动或删除后仍可再次编辑。
- 连接设置显示生成/编辑能力状态，兼容服务不支持编辑端点时给出明确提示。

## 安装包

- macOS Apple Silicon：适用于 M1、M2、M3、M4、M5 等 Apple 芯片设备。
- macOS Intel：适用于 Intel 芯片 Mac。
- Windows x64：适用于 64 位 Windows 10/11。

> EmberImage 目前未进行 Apple 或 Microsoft 代码签名。首次启动时，系统可能显示安全提示，请确认安装包来自本仓库的官方 Release 页面。
