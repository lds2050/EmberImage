## 本次更新

v0.6.0 带来 **多模型支持**：同一个界面即可切换 **OpenAI 兼容 / Seedream（火山方舟）/ Gemini** 三种接口，各自有独立适配器与能力提示。同时优化了「新增连接」的交互——点新建后配置会**立即出现在左侧列表**（草稿态），不再等到保存。

### 多模型支持

- 连接编辑器新增**接口类型**选择：OpenAI 兼容 / Seedream / Gemini，切换时自动给出对应服务的默认 Base URL、模型名与能力说明。
- **Seedream**（火山方舟）：文字生图 + 参考图编辑；输出默认关水印；编辑走 JSON 内嵌图片数组。
- **Gemini**（Google）：文字生图 + 参考图编辑；一次请求出一张，多张自动串行；可配 1K/2K/4K 档位与宽高比。
- **能力差异自动提示**：连接列表与编辑器里实时展示「文字生图 / 参考图编辑 / Mask 局部编辑」支持情况；Seedream 与 Gemini 不支持 Mask 局部编辑时，编辑面板的「局部编辑」入口会自动置灰并给出引导。
- 主进程请求管线统一走 Provider 适配层，各接口的响应形状差异（OpenAI `data` vs Gemini `candidates`）由适配器归一处理。

### 交互优化

- 点击「新增连接」或「新建 OpenAI 默认配置」后，配置**立刻**以「草稿」状态插入左侧连接列表（虚线框 + 草稿标记），无需等保存才看到。
- 填完保存即转正式连接；切换其他连接或离开时自动丢弃草稿；重复点击不会堆叠出空条目。

### 界面

- 左侧连接列表每项显示接口类型标签，一眼区分多份连接的归属服务。
- 连接编辑器展示接口能力三档点，与按实际请求标记的「服务能力状态」互补。

## 安装包

- macOS Apple Silicon：适用于 M1、M2、M3、M4、M5 等 Apple 芯片设备。
- macOS Intel：适用于 Intel 芯片 Mac。
- Windows x64：适用于 64 位 Windows 10/11。

> EmberImage 目前未进行 Apple 或 Microsoft 代码签名。首次启动时，系统可能显示安全提示，请确认安装包来自本仓库的官方 Release 页面。
