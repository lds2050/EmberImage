## 本次更新

- 素材卡片支持拖拽排序，直接拖动卡片即可调整图片顺序。
- 导入带旋转信息的 JPEG（如手机竖拍照片）时自动摆正方向，缩略图与提交给服务的图片保持一致。
- Mask 编辑器新增快捷键：[ ] 调整画笔大小，⌘/Ctrl+Z 撤销、⌘/Ctrl+Shift+Z 重做。
- Mask 编辑器新增"反选"：一键把编辑区域切换为已标记范围的补集。
- 图片查看器中的编辑区域标记改为逐像素精确对齐，调整窗口大小不再错位。
- 启动时自动清理上次运行残留的临时素材与缩略图缓存。

## 安装包

- macOS Apple Silicon：适用于 M1、M2、M3、M4、M5 等 Apple 芯片设备。
- macOS Intel：适用于 Intel 芯片 Mac。
- Windows x64：适用于 64 位 Windows 10/11。

> EmberImage 目前未进行 Apple 或 Microsoft 代码签名。首次启动时，系统可能显示安全提示，请确认安装包来自本仓库的官方 Release 页面。
