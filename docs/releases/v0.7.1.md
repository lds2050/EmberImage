## 本次更新

v0.7.1 带来 **GPT Image 2.5 系列支持**：OpenAI 于 9 月 8 日发布 `gpt-image-2.5-flare`（比上一代快 50%）与 `gpt-image-2.5-sunburst`（精修档，多轮编辑一致性更强）。本次更新把新模型与新增质量档位接入现有工作流，默认模型同步升级。

### GPT Image 2.5 支持

- **质量档位扩展为六档**：自动 / 低 / 中 / 高 + 新增**超高（xhigh）**与**极致（max）**；后两档为 2.5 系列专属，旧模型（如 `gpt-image-2`）不支持时会收到服务端的明确报错；
- **默认模型升级为 `gpt-image-2.5-flare`**：新建 OpenAI 默认配置、连接编辑器与默认连接均预填新模型；`gpt-image-2` 仍可用，随时改回；
- **模型名称改为预设下拉**：按接口类型提供预设建议（OpenAI 兼容含 flare / sunburst / 2 三档），同时**保留自由输入**，自定义模型名不受影响；
- 现有参数体系（尺寸 16 倍数与 3840px 上限、16 张参考图、数量 1–10、流式部分图）与 2.5 规格完全一致，无需改动。

### 其他

- 尺寸超限报错文案从「GPT Image 2」更新为「GPT Image 系列」。

## 安装包

- macOS Apple Silicon：适用于 M1、M2、M3、M4、M5 等 Apple 芯片设备。
- macOS Intel：适用于 Intel 芯片 Mac。
- Windows x64：适用于 64 位 Windows 10/11。

> EmberImage 目前未进行 Apple 或 Microsoft 代码签名。首次启动时，系统可能显示安全提示，请确认安装包来自本仓库的官方 Release 页面。
