## 本次更新

本版本带来独立的**提示词库**：把好用的提示词沉淀下来，分类、搜索、收藏、统计使用次数，随时一键取用。同时修复了一个兼容服务的流式参数报错。

### 提示词库

- 主导航新增「提示词」页：新建 / 编辑 / 删除提示词，支持正文与自由分类，分类输入自动联想已有名称。
- **分类筛选**：顶部分类 chips 单选过滤（含条目计数），与搜索叠加生效。
- **模糊搜索**：多关键词空格分隔，全部命中才匹配，同时搜正文与分类。
- **收藏置顶**：卡片星标一键收藏，收藏的永远排最前。
- **使用次数**：每次「用于生成」自动计数，排序规则为收藏 → 使用次数 → 最近更新，常用提示词越用越靠前。
- **批量管理**：多选删除、批量移动到分类，支持 Esc 快速退出。
- **分类重命名**：选中分类 chip 后一键重命名，该分类下所有条目批量更新，重名自动合并。
- **双向转存**：生成页与画廊卡片菜单都能一键「存入提示词库」，自动查重不重复入库；卡片菜单支持复制文本。
- 数据本地存储于 `prompts.json`（上限 500 条），不上传任何内容。

### 界面调整

- 侧边栏与工具栏的统计数字（记录数 / 提示词条数）全部移除，界面更干净。
- 「用于生成」现在总是切换到文字生图模式（此前会沿用上次停留的模式）。

### 修复

- 部分兼容服务（网关）会把流式请求的 `stream` 参数剥离却透传 `partial_images`，导致生成报 400「partial_images requires stream=true」。客户端现在会识别这种情况并**自动改用非流式重试**，出图不受影响，仅提示一次。

## 安装包

- macOS Apple Silicon：适用于 M1、M2、M3、M4、M5 等 Apple 芯片设备。
- macOS Intel：适用于 Intel 芯片 Mac。
- Windows x64：适用于 64 位 Windows 10/11。

> EmberImage 目前未进行 Apple 或 Microsoft 代码签名。首次启动时，系统可能显示安全提示，请确认安装包来自本仓库的官方 Release 页面。
