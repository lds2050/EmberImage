## 本次更新

本版本围绕「精确控制要改哪里」：Mask 编辑器新增整套选区工具，并附带一个纯本地的背景移除功能。

### 选区工具

- **魔棒**：按颜色相似度扩散选中，容差 0–128 可调，支持「连续」（仅相连区域）与「全图」（画面内所有颜色相近区域）两种范围。
- **套索**：手绘多边形轮廓，松开鼠标自动闭合。
- **自动主体**：一键圈出画面主体。长边超过 2048px 的图片先降采样计算再映射回原尺寸，大图也不会卡住界面。
- **Shift 加选 / Alt 减选**：同一张图上可以反复叠加或挖去范围。
- 选区支持**反选**、**羽化**（0–20，让边缘从一刀切变成渐变过渡）与**取消**。
- **应用为 Mask**（按钮或 `Delete` 键）：选区与手涂笔画进入同一套撤销栈，可以混合撤销、重做。
- `Esc` 取消当前选区。
- 选区计算跑在独立 Worker 中；Worker 初始化失败或超时会自动降级为主线程计算，界面不会卡死。

### 背景移除

- 入口：素材卡片右键菜单，或双击预览后查看器右上角的「移除背景」。
- 本地识别主体并把背景转为透明，边缘自动羽化，**不消耗 API 额度**。
- 棋盘格预览确认效果后，可导出透明 PNG，或一键加入素材面板继续参与编辑。

### 其他改进

- 素材卡片新增右键菜单：放大预览、移除背景、移除素材。
- 侧边栏底部显示当前版本号，并可直接跳转到项目主页。
- 移除了内置的示例图片与示例提示词 —— 提示词管理能力会在后续版本以更合适的形态提供。
- 默认窗口尺寸调整为 1360 × 900，设置页压缩为一屏显示，无需滚动。
- 关闭 Mask 编辑器后释放主图位图缓存，大图反复开关不再持续占用内存。

## 安装包

- macOS Apple Silicon：适用于 M1、M2、M3、M4、M5 等 Apple 芯片设备。
- macOS Intel：适用于 Intel 芯片 Mac。
- Windows x64：适用于 64 位 Windows 10/11。

> EmberImage 目前未进行 Apple 或 Microsoft 代码签名。首次启动时，系统可能显示安全提示，请确认安装包来自本仓库的官方 Release 页面。
