## 本次更新

v0.7.0 带来**多轮对话式连续图像编辑**：新增独立的「会话」页，以一张基准图开启会话后逐轮输入指令连续修改，像聊天一样迭代出图。支持**会话链**与 **Gemini 原生多轮**两种模式，配合聊天式对话流、分叉与旧会话继续。

### 多轮对话改图

- 新增「会话」导航页：从画廊/生成结果「会话继续」或直接选择图片开启会话，逐轮下指令连续改图；
- **会话链**模式：每轮把上一轮结果作为参考图继续编辑，复用参考图编辑通道，**三种接口通用**（OpenAI 兼容 / Seedream / Gemini）；
- **Gemini 原生多轮**：把完整对话历史回放给模型，`thoughtSignature` 逐轮原样保存与回传，上下文最连贯；需 Gemini 连接，其他接口的会话会明确提示并保持会话链可用。

### 对话流界面

- 微信式左右气泡：用户指令在右、AI 结果在左，均带时间戳；AI 气泡展示本轮基准图与结果图；
- 发送后出现**生成中读秒**气泡，完成或失败自动替换为结果/错误；
- 失败轮保留错误气泡，支持**一键重试**；
- 头部标签实时显示**模型、模式、尺寸、画质、格式、轮数**等核心参数。

### 分叉与继续

- 任一历史轮的结果图可**设为新基准**，从该点继续探索不同方向；
- 旧会话随时打开继续，历史轮只读回放，发送区定位到最新轮；
- 打开旧会话时自动回填当轮参数标签。

### 稳定性

- 网络层失败（如连接被中转静默关闭）给出可读的错误说明，不再显示笼统的「请求失败」；
- 请求日志深度脱敏：图片 Base64 等敏感载荷永不落盘。

## 安装包

- macOS Apple Silicon：适用于 M1、M2、M3、M4、M5 等 Apple 芯片设备。
- macOS Intel：适用于 Intel 芯片 Mac。
- Windows x64：适用于 64 位 Windows 10/11。

> EmberImage 目前未进行 Apple 或 Microsoft 代码签名。首次启动时，系统可能显示安全提示，请确认安装包来自本仓库的官方 Release 页面。
