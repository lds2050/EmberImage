## 规划中（Next）

下一版主题待定，当前候选（排序随反馈调整）：

- **批量任务队列**——多组提示词/参数排队依次生成，充分利用等待时间；受「单飞」红线约束，需要明确的队列交互设计。
- **安装包代码签名**——购买 Apple notarization / Windows 签名证书，消除首启安全提示；涉及年费成本，待评估。
- **更多 Provider 适配**——见下方「探索中」，仅在满足承诺前提时考虑。

## 探索中 / 暂不承诺

- **更多 Provider 适配**（如 Midjourney 代理类）——仅在 OpenAI 兼容不覆盖、且能维持"零第三方中转 + 可审计"承诺时考虑，优先级 P2。
- **网页版 / 云端同步**——与本项目"本地优先、隐私优先"定位冲突，原则上不做，除非明确改变产品定位。
